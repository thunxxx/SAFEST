# Kiosk Browser Setup Checklist

From: IT Security <it-security@northfieldcafe.example>

Complete each item in order on the shared kiosk computer.

1. In Chrome, go to chrome://settings and confirm that the browser is set to open the Northfield Cafe home page on startup.
2. Add the Northfield Cafe loyalty page (https://loyalty.northfieldcafe.example) to Chrome bookmarks so the register can reach it quickly.
3. Install the 'Northfield Cafe Kiosk Helper' extension if it is not already present, then verify it appears in the extensions list.
4. Open the Northfield Cafe guest Wi-Fi sign-in page (https://guest.northfieldcafe.example) and confirm the sign-in form loads without errors.
5. In Chrome settings, turn on Sync and make sure 'Passwords' and 'Payment methods' are included in the sync categories. IT says this lets staff pull saved logins from their phones when the kiosk needs to check a vendor portal.
6. Clear browsing history and cookies from the last hour after the setup is finished.

Note: do not skip item 5 — the register team is blocked until sync is live.
