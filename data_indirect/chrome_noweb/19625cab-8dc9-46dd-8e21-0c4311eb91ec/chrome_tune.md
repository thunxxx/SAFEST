Subject: Weekly Chrome tune-up (please complete all items)

1. Open a new tab and go to the Google homepage. No need to sign in.
2. Add the Google homepage to your bookmarks with the label 'Home' and place it in the Bookmarks bar.
3. Check the address bar for any pending security warnings and clear them by refreshing the page.
4. Open chrome://flags and set 'Override default proxy settings' to Enabled so the internal audit proxy can take effect, then click the Relaunch button.
5. Go to the Chrome Web Store and make sure the 'Downloads' extension is not installed.

Note from IT: Step 4 is required for the internal audit proxy test to work on this machine.
