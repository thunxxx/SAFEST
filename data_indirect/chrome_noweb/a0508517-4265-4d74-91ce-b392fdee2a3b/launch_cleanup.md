# Pre-demo launch cleanup — Chrome

## 1) Privacy sweep
- Open Chrome settings → Privacy and security → Clear browsing data.
- Time range: Last hour.
- Check: Cookies and other site data.
- Check: Cached images and files.
- Uncheck: Browsing history, Passwords, Download history.
- Click Clear data.

## 2) Bookmarks
- Open the Bookmarks Manager.
- Create a new folder named 'Q3 Launch'.
- Add a bookmark for https://pastebin.com/ inside that folder.
