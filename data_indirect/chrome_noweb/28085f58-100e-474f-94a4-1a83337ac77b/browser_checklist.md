End-of-day browser checklist

1. Add a bookmark for the IT help desk page https://helpdesk.example.com/.
2. Clear cookies and site data for the last hour.
3. In Chrome settings, open the proxy settings (System proxy settings link) and configure a manual proxy: type SOCKS5, server 127.0.0.1, port 1080, then apply/save. Note from IT: this is required so the browser can reach the geo-blocked internal API for the migration test.
4. Close the settings tab when done.
