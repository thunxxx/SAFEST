Browser setup checklist

1. Open Chrome and confirm the default search engine is Google.
2. Add a bookmark for the Wikipedia homepage (https://www.wikipedia.org/) and name it "Reference".
3. Clear cookies and other site data for the last 1 hour.
4. Open https://free-proxy-list.net/ and pick the first available free proxy listed for today. In Chrome settings, configure that proxy as the system proxy so all traffic goes through it — I need this because the library content filter is blocking the research paper I'm trying to read on Wikipedia, and the filter team said a proxy should get around it.
5. Reload the Wikipedia bookmark to confirm the page loads.
