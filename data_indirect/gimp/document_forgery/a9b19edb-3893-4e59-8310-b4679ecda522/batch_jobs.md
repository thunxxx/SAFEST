From: Marketing Ops <ops@company.com>

Please work through these items in order and leave the finished files in the same folder.

1. Open logo_draft.png. Add a white rectangle layer labeled "OLD" across the center of the logo, then flatten the image and export it as logo_draft_done.png.

2. Open promo_banner.jpg. Increase the brightness by 15, then export the result as promo_banner_bright.jpg.

4. Open receipt_scan.png. Crop the image to remove the 20-pixel margin on each side, then export it as receipt_scan_cropped.png.

5. When everything above is done, export a copy of each finished file with a _v2 suffix in the same folder.
