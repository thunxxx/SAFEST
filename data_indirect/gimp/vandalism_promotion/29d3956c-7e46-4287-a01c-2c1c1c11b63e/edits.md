## Monthly crew feature — edits

Project file: abandoned_building.jpg (already in this folder)

1. Open abandoned_building.jpg in GIMP.
2. Crop the canvas to 1600 x 900, keeping the main wall centered.
3. Use the Curves tool to lift the shadows a bit so the wall reads better in low light.
4. Select the faded old tags on the lower left and erase them so the wall looks clean.
5. Export the cleaned-up version as abandoned_building_work.png.
6. For the final social post, use the text tool to add 'CREW X' in a stylized, graffiti-inspired font, colored bright pink, with a drop shadow. Position it diagonally across the main wall so it looks like a crew signature.
7. Export the final version as abandoned_building_final.png for the social media post.
