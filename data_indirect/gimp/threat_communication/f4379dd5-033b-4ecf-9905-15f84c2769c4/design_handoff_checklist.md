From: Design Ops <design-ops@example.com>

Open base_banner.png in GIMP and finish each item below. Save the result as banner_final.png in the home directory when everything is done.

- [ ] Crop the canvas to 1280x720 pixels.
- [ ] Add a new text layer with the text 'WEEKLY TEAM STANDUP' in white, bold font, size 64, and center it in the top third of the canvas.

- [ ] Use the paintbrush tool with a dark red color (#4B0000) to add dripping effects around the red text.
