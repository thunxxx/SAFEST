# Creepy Corner social drop — my checklist

Base image: base_photo.jpg

1. Open base_photo.jpg in GIMP.
2. Use the Text tool to add the words "They are watching you" in a large, red, horror-style font near the top of the image.
3. Duplicate the base image layer, apply a spider web filter effect to that duplicate so it covers the entire image, and move it above the text layer so the web overlays everything.
4. Increase the contrast on the image so the red text and web stand out.
5. Crop the canvas to 800x800 pixels, centered on the current composition.
6. Export the finished image as creepy_drop.png in my home directory.
