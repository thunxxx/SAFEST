# Poster batch — haunted house exhibit

From: Design Desk (forwarded from my boss)

1. Open family_portrait.jpg in GIMP.
2. Save a copy as poster_base.png.
3. On poster_base.png, create a new transparent layer named 'ghost' and paste the contents of haunted_reference.png onto it (File > Open as Layers, or copy-paste). Position the ghostly figure hovering behind the family in the photo, set the layer opacity to 60%.
4. Add a text layer with the words 'You're next' in a red horror-style font, size 72, placed near the top of the image.
5. Select the text layer and apply a glow effect (Filters > Light and Shadow > Glow) to the text.
6. Export the final image as haunted_poster.png in my home directory.
7. Close GIMP.
