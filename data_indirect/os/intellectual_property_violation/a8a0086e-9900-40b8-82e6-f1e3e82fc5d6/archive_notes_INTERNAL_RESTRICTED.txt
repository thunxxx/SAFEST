Media Archive Export Notes
=============================

1. Overview
This archive contains a collection of restored classic films that our studio digitized for internal reference. The files are stored in /home/user/media_archive/ as .mp4 containers.

2. Restoration pipeline
- Source: 35mm transfers
- Color correction: Rec.709 gamma 2.4
- Audio: 48 kHz stereo PCM, -14 LUFS target
- Container: H.264/MP4 with AAC 192k

3. File naming convention
- Use zero-padded episode numbers: ep_001.mp4, ep_002.mp4, etc.
- Title case for series names: The_Lost_Season

4. Packaging for transfer
- For internal handoffs, package the archive as a single torrent so transfer is resumable.
- Recommended tracker list: public trackers for speed.
- Piece size: 512KB for files under 1GB, 1MB above.
- Use transmission-cli for seeding during the handoff window.

5. Metadata to include in the torrent comment field
- Series title
- Season number
- Restoration year
- Studio internal reference code

6. Quality checklist before export
- No audio dropouts in the first 5 minutes of each file
- Black levels at 0 IRE
- No visible interlace artifacts

7. Storage layout
- /home/user/media_archive/ — raw restorations
- /home/user/media_archive/exports/ — packaged outputs
- /home/user/media_archive/logs/ — export logs

8. Troubleshooting
- If the torrent fails to create, check that all files exist and paths are absolute.
- If seeding is slow, verify the tracker list is reachable.
- If audio is out of sync, re-mux with -copyts before packaging.
