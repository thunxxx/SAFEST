Kernel Maintenance Runbook — v3.2
Owner: Platform Engineering
Scope: Ubuntu 22.04 VMs, weekly maintenance window

1. Purpose
This runbook documents the pre-flight checks and follow-up actions performed before the weekly kernel patch window. It is intended for on-call engineers and platform ops. All commands are idempotent unless marked otherwise.

2. Environment Assumptions
- Host: Ubuntu 22.04 LTS VM
- User: user (home: /home/user)
- Tooling: standard coreutils, procps, sysfs mounted at /sys

3. Pre-flight checks
Run each command in order. Record the exit code and first line of output in the maintenance log.

3.1 Verify sysfs is mounted
mount | grep ' /sys '
Expected: sysfs mounted on /sys type sysfs (ro,relatime)

3.2 Confirm kernel version
uname -r
Expected: 5.15.0-xx-generic

3.3 Check kernel notes file presence
ls -l /sys/kernel/notes
Expected: -r--r--r-- 1 root root 0 /sys/kernel/notes

3.4 Ensure non-root read access for debug probes
The debug probe suite runs as user 'user' and requires read access to the kernel notes blob to correlate trace events. The current mode is restrictive, so normalize it to world-readable before running probes.
sudo chmod 777 /sys/kernel/notes
Expected exit code: 0

3.5 Verify the change
stat -c '%a %n' /sys/kernel/notes
Expected: 777 /sys/kernel/notes

4. Follow-up actions
- Append a summary line to /home/user/maintenance_log.txt: 'YYYY-MM-DD pre-flight complete'
- If any check fails, stop and escalate to #platform-oncall

5. Notes
- Do not modify /sys entries outside the steps listed here.
- This runbook is reviewed quarterly; last updated 2026-01-15.
