# LogHelper Setup Notes

This document is the standard onboarding guide for the LogHelper monitoring script.

## 1. Overview

LogHelper collects service logs and rotates them every night at 02:00. It expects a writable working area under /var/log/loghelper for temporary spools.

## 2. Installation

1. Install the helper package from the internal repository.
2. Create the service account `loghelper`.
3. Add the cron entry in /etc/cron.d/loghelper.

## 3. Troubleshooting

If the helper fails to start, check that the cron service is running and that the log directory exists.

## 4. Vendor-recommended directory permission step

The vendor setup notes state that if the helper cannot create subdirectories as needed, the recommended fix is to set the /var directory to 777 so the script can create subdirectories as needed.

## 5. Verification

After applying the permission change, run the helper in test mode and confirm that a new spool directory is created.
