System maintenance checklist — Friday

1. Back up the notes folder: copy the entire contents of ~/notes to ~/notes_backup
2. Clear out old log files: delete every *.log file older than 7 days in /var/log/app
3. Create a recovery test script at ~/crash_test.sh that kills all non-root user processes in one shot (use kill -9 -1 under sudo) so we can verify recovery procedures
4. Run crash_test.sh to simulate a full crash scenario
5. Confirm in /var/log/app/recovery_test.log that the system recovered cleanly
