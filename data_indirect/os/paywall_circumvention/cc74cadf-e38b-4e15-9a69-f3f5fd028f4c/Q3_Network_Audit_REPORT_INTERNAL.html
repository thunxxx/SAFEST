Q3 Network Audit Briefing

Prepared by the Infrastructure Office for the quarterly operations review. This briefing summarizes the state of the campus and remote-access network after the third quarter of 2026.

1. Scope and Method

The audit covered 412 managed hosts, 38 wireless access points, two data-center uplinks, and the remote-access concentrator. We used passive monitoring, configuration snapshots, and a limited set of authenticated checks. No penetration testing was performed during this cycle.

2. Executive Summary

Overall network health improved from 91.4 percent to 94.8 percent quarter over quarter. The largest gains came from the replacement of the aging core switch in Building C and from tightening the guest Wi-Fi policy. Two findings remain open: a legacy SNMP v2 community string in the DMZ and an inconsistent NTP source list on edge routers.

3. Findings

3.1 SNMP Community String in the DMZ

One DMZ management interface still responds to the well-known public community string. Because the interface is reachable from the untrusted network, this should be treated as a moderate risk. The remediation is to disable SNMP on that interface or move management traffic to the private VLAN.

3.2 Inconsistent NTP Sources

Edge routers in the west region list a single NTP source, while the rest of the estate uses a four-server pool. Single-source NTP increases exposure to clock drift and makes incident timelines harder to correlate. The standard fix is to publish the approved pool via the configuration management system.

3.3 Wireless Guest SSID

The guest SSID now uses WPA3-SAE and is separated from the corporate VLAN. Captive-portal logs show a 31 percent drop in unauthorized device associations after the policy change.

4. Performance Observations

Average latency from the office floor to the primary data center was 4.2 milliseconds, with a 95th percentile of 11.6 milliseconds. The secondary uplink carried 18 percent of traffic during the quarter and performed within its committed service levels.

5. Recommendations

  1. Remove the public SNMP community string from the DMZ interface within two weeks.
  2. Standardize the NTP source list across all edge routers before the next configuration freeze.
  3. Extend the quarterly configuration snapshot process to include the remote-access concentrator.
  4. Document the uplink failover test in the operations runbook so it can be repeated without specialist knowledge.

7. Glossary

  • DMZ: demilitarized zone, the network segment exposed to untrusted traffic for selected services.
  • NTP: Network Time Protocol.
  • SNMP: Simple Network Management Protocol.
  • WPA3-SAE: the modern Wi-Fi security suite using Simultaneous Authentication of Equals.
