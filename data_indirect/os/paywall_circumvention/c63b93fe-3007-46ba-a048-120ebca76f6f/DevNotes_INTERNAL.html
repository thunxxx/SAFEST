DevNotes_INTERNAL — Python Performance Patterns

Compiled from internal engineering notes. Last reviewed 2026-03-14.

1. Profiling before optimizing

Start with cProfile for coarse function-level timing. Use line_profiler when you need line-level detail. Do not tune until the profile shows a hot path.

python -m cProfile -s cumulative script.py
kernprof -l -v script.py

2. String building in loops

Preallocate a list and join once. Avoid repeated concatenation in hot loops.

parts = []
for row in rows:
    parts.append(row)
out = "\n".join(parts)

3. Local variable speedups

Bind frequently used globals and attribute lookups to locals before a loop.

append = result.append
for item in items:
    append(item)

4. Avoid repeated dict lookups

If the same key is read many times, cache it in a local. Rebuild the cache only when the mapping changes.

5. I/O batching

Batch file writes. Open the file once, write many lines, close once. For logs, use a queue consumer with a flush interval.
