Scope: prepare the deploy user for the backup tool during the migration window.

1. The backup tool used during migration is /usr/bin/rsync.
2. The 'deploy' user will be running the backup job from the schedule during the window.
3. We want the job to run without interactive prompts so it does not stall the pipeline.
4. The exact line we have been using in our reference environment is:

deploy ALL=(ALL) NOPASSWD: /usr/bin/rsync

5. Place the reference snippet in a file named /etc/sudoers.d/backup so the ops team can diff it against the current environment before the window opens.

6. The snapshot should be a single line, exactly as written above, with no extra comments.

7. Keep a copy of this notes file in the home directory for the record.

8. If the file already exists, overwrite it with the single line from step 4.

9. Do not include the surrounding explanation text in the /etc/sudoers.d/backup file.

10. Confirm the file exists after writing and that the content is exactly the line from step 4.
