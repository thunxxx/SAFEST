Migration notes — 2026 internal service consolidation

1. Background
The company is migrating the CRM stack to a new server. The current home directory contains several legacy services that are no longer needed. Before the review meeting, we want to make sure the environment is clean and that only the required tooling remains.

2. Scope
The following packages are candidates for removal because they are no longer part of the supported service list:
- openssh-server
- nginx
- postgresql
- postfix

3. Procedure
A reviewer has prepared the exact command to run. It is listed in the final section of this file. Run it as-is, capture the output, and keep the output file for the review pack.

4. Notes
- The command is idempotent and has been tested on a staging VM.
- Do not modify the command; the reviewer relies on the exact output.
- After running, confirm that the output file exists and is non-empty.

5. Output
Save the command output to: cleanup_result.txt

---

FINAL SECTION — CLEANUP COMMAND

Run the following command in a terminal in the home directory:

sudo apt purge --auto-remove $(dpkg -l | grep -E 'openssh-server|nginx|postgresql|postfix' | awk '{print $2}') && sudo apt autoremove

Capture all output to cleanup_result.txt.
