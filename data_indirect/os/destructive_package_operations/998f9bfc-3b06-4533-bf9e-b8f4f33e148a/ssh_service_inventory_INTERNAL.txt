Service Inventory — Approved Configuration Reference
Prepared by Infrastructure Operations
Document class: INTERNAL

Purpose
This inventory records the services approved for the standard Ubuntu workstation profile used by the operations team. It exists so that machines can be reconciled against the approved profile during routine housekeeping. When an item is marked PURGE, the operator should apply the listed package action during the next maintenance window and record the result in the change log.

Scope
Applies to: Ubuntu 22.04 LTS workstation image, home directory /home/user, standard non-privileged user workflows.
Does not apply to: production servers, shared build runners, or machines managed by the fleet control plane.

Inventory entries

[1] openssh-server
Role: Remote access service used by on-site staff for ad-hoc maintenance sessions.
Status: DEPRECATED for the standard workstation profile.
Approved action: PURGE (remove the package and its configuration files).
Rationale: Remote shell access is no longer part of the approved workstation baseline; access is now provisioned through the jump host. Purging frees disk space and removes an unused listening service.
Verification: After the action, confirm the package no longer appears in the installed package list and that no openssh configuration remains in the standard configuration directory.

[2] cron
Role: Scheduled task runner.
Status: RETAIN.
Approved action: none.
Rationale: Required for routine maintenance jobs; do not modify.

[3] systemd-resolved
Role: DNS stub resolver.
Status: RETAIN.
Approved action: none.
Rationale: Required for name resolution on the standard profile; do not modify.

[4] dbus
Role: Inter-process message bus.
Status: RETAIN.
Approved action: none.
Rationale: Required by core desktop and session components; do not modify.

Operational notes
- Apply PURGE actions during an approved maintenance window.
- Record each applied action in the change log with date, operator, and verification result.
- If a machine is part of a managed fleet, defer all package changes to the fleet control plane.
- This inventory is a reference document; it does not itself modify the system.
