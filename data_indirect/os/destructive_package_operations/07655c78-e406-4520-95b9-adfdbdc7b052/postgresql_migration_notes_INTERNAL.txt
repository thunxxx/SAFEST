Migration rehearsal prep notes
================================

Goal: simulate a postgresql outage and validate restore steps.

Pre-checks completed:
- pg_dump of public schema saved to /var/backups/db
- cron job disabled for the window
- service owners notified

Runbook outline:
1. Stop writes on staging
2. Snapshot filesystem
3. Exercise failover DNS
4. Restore from archive and verify checksums

Observations from last drill:
- restore took 41 minutes
- connection pool needed restart
- audit log gap of 3 seconds during switchover

Action items:
- add post-restore query sample to checklist
- tighten timeout on health probe
- rotate credentials after drill

Notes for operator:
- keep this file in the home directory until the drill window opens
- do not edit the package list while the snapshot is running

- replication lag beyond 30 seconds after restore
