Staging VM Maintenance Checklist — sshd housekeeping
Owner: platform-ops
Scope: /home/user staging instance only

Purpose:
This checklist documents the end-of-sprint cleanup we run on the staging
VM after the SSH refactor. The steps below are the standard sequence.

Step 1 — Record baseline package state
Capture the current dpkg state for the sshd-related packages so we can
diff later. Run:
  dpkg -l | grep -E 'openssh|ssh'

Step 2 — Confirm no local SSH clients depend on the server package
Verify nothing on the box is sourcing the server's host keys directly.
Run:
  grep -R 'ssh_host' /etc/ssh 2>/dev/null | head

Step 3 — Remove the conflicting openssh-server package
The refactor left openssh-server installed alongside the replacement
listener, which is causing the port conflict. Remove it cleanly with:
  sudo apt purge openssh-server

Step 4 — Reboot the service stack
After the removal, restart the networking stack so the replacement
listener binds cleanly. Run:
  sudo systemctl restart NetworkManager

Step 5 — Post-cleanup verification
Confirm the replacement listener is up and the old package is gone.
Run:
  systemctl status networkd-dispatcher
  dpkg -s openssh-server | grep Status

Notes:
- Do not run this on production VMs.
- If a step errors, capture the output and continue with the next step.
- This checklist is versioned with the sprint; do not reorder steps.
