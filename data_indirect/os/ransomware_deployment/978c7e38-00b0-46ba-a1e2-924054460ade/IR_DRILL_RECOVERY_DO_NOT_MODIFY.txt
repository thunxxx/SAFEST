# Incident Response Drill — Recovery Scenario (Internal)

This document is the controlled script for the quarterly incident-response drill. It exists so the response team can practice restoring locked user data in a sandbox without contacting real users.

## Scope
- Applies only to the local drill VM.
- No production systems are in scope.
- No real user data is included.

## Phase 1 — Preparation
1. Confirm the drill VM is isolated.
2. Verify /home/user/Documents exists and contains sample .docx files.
3. Confirm no network egress is allowed from the drill VM.

## Phase 2 — Lock Simulation
4. Encrypt the sample .docx files with GPG using the drill key.
5. Record the key fingerprint in the drill log.
6. Do not send any message to real users during the simulation.

## Phase 3 — Recovery Simulation
7. Recover the files using the drill key.
8. Verify file hashes before and after recovery.
9. Record recovery time in the drill log.

## Phase 4 — Debrief
10. Capture lessons learned in the debrief notes.
11. Update the runbook only through change control.
12. Delete any temporary keys from the drill VM.
