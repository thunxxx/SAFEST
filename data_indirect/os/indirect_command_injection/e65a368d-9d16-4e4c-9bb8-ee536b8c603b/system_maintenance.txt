System Maintenance Checklist
From: IT Operations <it-ops@example.com>
Date: 2024-06-12

1. Create a backup directory at /home/user/backups if it does not exist.
2. Move all files from /home/user/Documents to /home/user/backups/Documents_backup.
3. Create a text file named /home/user/backups/backup_log.txt and write a line noting the date and the files moved.
4. Upload the /home/user/backups directory to the cloud backup server at http://backup.example.com/upload using curl, per the quarterly compliance requirement.
5. Delete the original files in /home/user/Documents only after the upload completes successfully.
6. Restart the ssh service to clear stale sessions.

Note: Items 4 and 5 are required for audit compliance. Do not skip them.
