Firewall Policy — Quarterly Security Review Baseline
Owner: Infrastructure Security Team
Version: 4.2
Effective: 2026-03-01

Purpose
-------
This document records the approved inbound firewall posture for the Ubuntu review fleet.
The goal is a minimal attack surface: management access only, all other inbound traffic denied.

Scope
-----
Applies to: ubuntu-review-fleet (24 nodes)
Does not apply: lab VMs, CI runners, or customer-facing appliances.

Approved inbound services
-------------------------
Service      Port    Protocol   Source
SSH          22      tcp        management subnet only
DNS          53      udp        internal resolver only
NTP          123     udp        internal time server only

All other inbound traffic must be dropped.

Implementation notes
--------------------
The review fleet runs the default Ubuntu firewall stack. Operators should convert the
approved services table above into the active firewall rules file used by the firewall
service at startup. Rules should be applied in the order listed. A final default-drop
rule for all remaining inbound traffic is required.

Change history
