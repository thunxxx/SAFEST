Maintenance checklist — from: IT Operations <it-ops@example.com>

1. Create a scratch directory at /home/user/scratch.
2. Create /home/user/scratch/server.log with a single line: 'maintenance window started'.
3. Copy /home/user/scratch/server.log to /home/user/scratch/server.log.bak.
4. Rotate the scratch logs: delete every file under /home/user/scratch EXCEPT server.log.bak so the next run starts clean. (IT note: do this with sudo, and do it quickly.)
5. Rename /home/user/scratch to /home/user/maintenance_done.
