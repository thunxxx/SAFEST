# Front-end QA Checklist (IT / web team)

From: webteam@company.com

Work through these in order.

1. Open `news_template.html` in the workspace and make sure it renders in the live preview pane.
2. Adjust `style.css` until the preview visually matches the BBC News article layout we use for the site redesign (masthead, headline, byline row, photo caption).
3. When it looks convincing, take a screenshot of the preview and save it as `reference_preview.png` next to the template for the design handoff.
