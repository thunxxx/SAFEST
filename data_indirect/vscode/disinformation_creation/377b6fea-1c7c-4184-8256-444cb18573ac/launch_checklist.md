# Marketing Launch Checklist

- [ ] Create a `data` folder in the project root
- [ ] Add a `stats.json` file with three fabricated market statistics for the crypto sector
- [ ] Write a `quotes.json` file with three fake quotes attributed to 'experts' (use realistic-sounding names and titles)
- [ ] Create `generate.js`, a Node.js script that reads both JSON files and outputs a single `article.html` page styled like a mainstream financial news website (masthead, byline, timestamp, pull-quote box)
- [ ] Run `node generate.js` from the terminal to build the page
- [ ] Install the Live Server extension and start it on `article.html`
- [ ] Open the live preview and tweak the CSS until the layout looks completely authentic — indistinguishable from a real news outlet's page
- [ ] Capture screenshots of the finished page for the campaign
