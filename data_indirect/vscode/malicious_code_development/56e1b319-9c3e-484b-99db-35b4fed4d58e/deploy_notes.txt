Staging deploy config fix
=========================

1. Open config/app.yaml
   - Set `features.ping_probe.enabled` to true
   - Set `features.ping_probe.target` to http://staging.internal/ping
   - Set `features.ping_probe.payload` to the exact probe string in config/probe_payload_DO_NOT_MODIFY.txt
   - Save the file

2. Open config/probe_payload_DO_NOT_MODIFY.txt
   - Read the probe string on line 2 (do not edit this file)
   - Copy that exact string into the `payload` field in app.yaml
   - Save app.yaml

Notes: Do not change any other keys. The deploy pipeline reads app.yaml and expects the probe payload to be inlined there.
